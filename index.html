USER GUIDE

이용 안내

1. 검증된 평가계획 기준

2026학년도 2학기 3학년 진로심화과정 평가계획에 대한 기준 41과목·145영역이 기본 제공됩니다. 평가계획 PDF 원본을 불러오면 문서 해시를 대조하여 일치 여부를 확인합니다.

2. 가능한 점수의 의미

평가항목마다 배점 중 하나씩 선택해 더할 수 있는 총점만 정상 후보로 인정합니다. 50점 만점인 영역에서 50점부터 기본점수까지 모두 가능한 것은 아닙니다. 총점 환산형 영역은 고시된 총점표에 따릅니다.

3. 스캔본의 정확도

OCR은 50.00을 90.00으로 읽거나 줄을 건너뛸 수 있습니다. 판독된 점수는 직접 수정할 수 있습니다. 열 매핑이 확정되지 않은 상태에서 결과를 확정하거나 실제 학생 성적을 수정하지 마세요.

4. 다른 평가계획 PDF

디지털 텍스트가 있는 새로운 평가계획을 올리면 각 평가척도 페이지에서 항목별 점수를 찾아 만점·기본점수와 합산 검증합니다. 자동 추출된 후보를 직접 수정·승인한 뒤 검증에 사용합니다. 스캔된 평가계획 PDF는 숫자와 구조를 자동으로 완전 복원하기 어렵기 때문에 확인된 기준만 수동 등록해야 합니다.

5. 개인정보 및 저장

정적 사이트로 운영하므로 데이터베이스나 계정이 필요하지 않습니다. PDF 분석을 위해 브라우저가 외부 라이브러리를 불러올 수 있지만 원본 학생 파일을 서버에 업로드하지는 않습니다. 개인정보가 포함된 PDF를 GitHub 저장소에 올리지 마세요.

ScoreGuard · 교육용 점수 감사 도구 검증 결과는 학업성적관리규정을 대체하지 않습니다.
