# ScoreGuard — 수행평가 점수 검증기

[GitHub 저장소](https://github.com/gim6110-glitch/suhangzumsu)

2026학년도 2학기 3학년 진로심화과정 평가계획 **41개 과목 / 145개 수행평가 영역 / 가능한 총점 3,188건**을 브라우저에서 검색하고, 수행평가 점수표 스캔 PDF를 OCR로 읽어 점수를 검증하는 정적 웹사이트입니다.

## Netlify 배포하기

1. Netlify → **Add new project** → **Import an existing project** → GitHub.
2. `gim6110-glitch/suhangzumsu` 선택.
3. Branch: `main`, **Build command: 비워둠**, Publish directory: `.` (점 하나).
4. **Deploy**. 이후 `main` 브랜치에 변경사항이 있으면 Netlify가 자동 배포합니다.

**Supabase 필요 없음.** HTML/CSS/JS 정적 사이트입니다. Python 설치도 필요 없습니다.

## 사용법

### 평가계획
- 기본 제공 2026 평가기준을 사용하거나 상단 **평가계획 PDF 선택**으로 원본을 불러옵니다.
- 원본 PDF와 **SHA-256 해시가 일치하면** 145개 영역의 검증된 가능 점수 목록을 재사용합니다.
- **다른 평가계획 PDF**의 점수는 자동으로 정확함을 보장할 수 없습니다. 해당 경우 PDF에서 '영역별 성취기준 / 평가척도' 페이지를 탐색해 표시하고, 교사가 항목별 점수를 입력해 **검토한 영역만 수동 등록**할 수 있습니다. 수동 등록한 항목은 현재 브라우저 세션에서만 유지됩니다.
- 기준 전체 CSV 저장: 영역별 가능한 점수 목록을 익명 CSV로 내보냅니다.

### 수행평가 일람표
- 스캔 PDF (최대 4개 파일, 파일당 20쪽)를 선택합니다.
- 사이트는 격자 가로선·세로선을 찾고 **학생 이름, 학번을 읽지 않는 점수 열만** OCR로 판독합니다.
- 교사는 학과/과목을 선택하고 **실제 영역 점수 열**을 연결합니다. 능력단위 소계·합계 열은 '검증 제외'로 둡니다.
- 검증 → 정상 / 오류 의심 / 예외 확인 / 판독 확인으로 분류.
- OCR이 불확실한 점수는 직접 수정 후 다시 판정합니다.
- **익명 결과 CSV 저장**: 파일 번호, PDF쪽, 학생 행 번호, 과목, 영역, 점수, 판정만 보존하고 이름/학번은 포함하지 않습니다.

### 브라우저 환경
- Chrome/Edge 등 최신 브라우저 권장. 네트워크가 필요합니다 (PDF.js와 Tesseract.js 라이브러리를 CDN에서 로드).
- 스캔 PDF OCR은 PC에서 권장합니다. 스캔 해상도에 따라 오래 걸릴 수 있으며 숫자 오인식 가능성이 있습니다.

## 개인정보 보호

- Netlify 사이트는 파일 자체를 받는 API를 제공하지 않습니다.
- PDF 파일은 브라우저 메모리에서 처리되고 외부 데이터베이스에 저장하지 않습니다.
- 개인별 성명·학번 열은 OCR 처리 대상에서 제외하도록 설계했으며, CSV에는 학생 행 번호만 저장합니다.
- 학생 개인정보가 포함된 PDF를 GitHub 저장소나 Netlify 관리 화면에 업로드하지 마세요.
- 페이지 내의 외부 CDN 리소스 로드는 인터넷 연결을 사용하지만 학생 PDF 원본을 전송하는 로직은 없습니다.

## 주의 사항

- **정상 판정은 ‘평가 항목의 배점 조합으로 가능한 점수’라는 뜻이지 실제 채점이 정확하다는 뜻이 아닙니다.**
- 합산형 아닌 특별 인정점, 출석·결시·전출·전입생 환산점은 별도 검토가 필요합니다.
- 제공 평가계획의 바리스타과 바텐더 '기획메뉴만들기'에는 원문 기본점수와 최저합계의 상충이 있어 자동 확정하지 않고 원문 확인 대상으로 표시합니다.
- OCR이 50.00을 90.00으로 오인식할 수 있습니다. **오류 의심 수치는 반드시 원본과 대조**하세요.
- 이미지 품질이나 서식이 다르면 자동 격자 추출에 실패할 수 있습니다. 이 경우 원본을 선명하게 스캔하거나 영역별 점수를 수동 검증하세요.
- 새 평가계획 PDF 전체 과목에 대한 무검토 완전 자동 추출 기능은 제공하지 않습니다. 정형성 없는 문서의 완벽 추출을 약속할 수 없기 때문입니다.

## 문제 해결

- 사이트가 빈 화면: 브라우저 새로고침 / 개발자도구 콘솔 오류 확인.
- OCR 라이브러리 실패: 인터넷 연결, 보안/광고 차단 프로그램, 학교망의 CDN 차단 확인.
- 일람표 인식 실패: 방향이 바로잡힌 고해상도 1쪽짜리 스캔 PDF로 먼저 테스트.
- 동일 과목명이 여러 학과에 있으면 **학과까지 선택**해야 정확한 배점과 연결됩니다.
